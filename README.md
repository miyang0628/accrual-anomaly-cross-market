# Replication Package — Cross-Market Accrual Anomaly / ESG-Proxy Study

Anonymous replication repository accompanying the manuscript submitted to
*[Anonymous Journal]*. Author information is withheld for double-anonymous
peer review.

This repository reconstructs the United States analysis of a Korea–United
States comparison of single-source ESG proxies, using only free, public data
so that the analysis is fully reproducible without any paid subscription.

## Scope of the proxies

- **G (total accruals)** — accrual-anomaly sort; the paper tests whether it
  prices returns AND forecasts profitability.
- **S (sin industry)** — sin vs. non-sin sort, classified from SIC codes
  (core: alcohol/tobacco/gaming; broad: + defense).
- **E (carbon efficiency)** — **not testable with free data**: firm-level
  emissions require a paid subscription (commercial carbon DB or CDP microdata),
  so the environmental pillar is declared out of scope rather than reported as
  a null.

## Data sources (all free, no paid subscription)

- **SEC EDGAR XBRL "frames" API** — firm-year accounting items.
- **SEC EDGAR submissions API** — SIC industry codes (for sin classification).
- **yfinance** — monthly adjusted equity prices.
- **Kenneth French Data Library** — market, size, value, momentum factors.

## Variable definitions

- Total accrual: `TACC = (NetIncomeLoss - NetCashProvidedByUsedInOperatingActivities) / Assets(t-1)`
- Gross profit over assets: `GPOA = (Revenues - CostOfRevenue) / Assets(t-1)`
- Sin flag: SIC-based (see notebook 05).
- Portfolio alphas: CAPM / FF3 / Carhart hedges.

## Execution status

Notebooks 01–06 are shipped **executed** (outputs embedded), reproducing the US
results end to end. Notebook 07 (Korea) requires a DART key and an unblocked
network, so it ships **unexecuted** with the authors' actual result recorded in

## How to run

Run the notebooks in order: `01 -> 02 -> 03 -> 04 -> 05`.
Set a descriptive User-Agent string in the EDGAR request headers before running
`01` and `05` (the committed value is an anonymous placeholder).

## Important limitations (see the manuscript for full discussion)

- The free price feed is **not survivorship-bias-free** and not point-in-time
  correct; delisted names may be missing, which inflates long-short returns and
  is the likely source of the large hedge magnitudes. The bias does not cancel
  across markets. Magnitudes should be read as directional; the manuscript
  emphasizes signs and the cross-market pattern.
- The main price universe is **capped** (deterministic, alphabetical) for
  runtime; the sin universe is collected separately in full. Re-estimate on the
  full CRSP universe with delisting returns before taking magnitudes literally.
- **Total accruals predicts returns but NOT future profitability** in the US
  sample (notebook 03 / manuscript Table 3), which is why the paper does not
  claim accruals is a governance-quality metric.
